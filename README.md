# CGT Clinical LLM

细胞与基因治疗（CGT）转化医学垂直语言模型 — 数据管线、持续预训练与评测。

> **项目代号。** 正式名称待定。候选名涉及在世医学家姓名，须取得本人或所属机构书面授权后方可对外使用；在此之前本仓库一律使用中性代号。

---

## 这是什么

面向**研究者发起临床研究（IIT）、preIND/IND 申报、临床方案设计**场景的领域语言模型。服务对象为 PI、临床研究者、CRO、转化医学团队与药监申报人员。

通用医疗模型在细胞与基因治疗、孤儿药认定、早期临床设计这些细分语域上知识稀薄且易产生幻觉。根因不在对齐不足，而在基座语言模型没有这套语域的 token 分布。本项目因此采用**先领域持续预训练（CPT）、后指令对齐（SFT）**的顺序，而非直接 SFT。

## 架构：三层分离

能力进权重，事实进检索，数据库进工具。这不是妥协，是工程边界。

| 层 | 内容 | 为什么在这一层 |
|---|---|---|
| **参数层**（CPT + SFT） | 监管话术、终点设计、统计方案、入排标准生成、SAE 分级推理 | 这些是语言与推理模式，必须进权重 |
| **检索层**（RAG，带条文级引用） | 各国法规条文、指南原文、药品说明书、流行病学统计 | 这些每月在变。写进权重等于固化一个会过期的版本，且**无法溯源**——申报文书必须能引用到出处 |
| **工具层**（函数调用） | ClinVar、ClinGen、Open Targets、ChEMBL、FDA 药品标签、ClinicalTrials.gov、PubMed/PMC | 模型要学的是何时调用与如何解读返回值，不是把数据库背下来 |

## 数据来源与许可

**全部训练语料均为公有领域或允许商业再利用的许可。** 本项目不使用、也不接受从 Claude、ChatGPT/Codex 等商业模型蒸馏产生的数据——相关服务条款禁止用其输出训练竞争性模型，而一个对外收费的医疗申报产品不应把这类数据放进来源链条。

| 来源 | 内容 | 许可 | 状态 |
|---|---|---|---|
| ClinicalTrials.gov API v2 | 6,267 份 CGT 干预性试验 | 美国政府作品，公有领域 | 已完成 |
| PMC Open Access（AWS Open Data） | CGT 文献全文，仅取 CC-BY / CC0 | CC-BY / CC0 | 进行中 |
| Federal Register API | FDA 法规与指南公告索引（707 份） | 美国政府作品，公有领域 | 索引层完成 |
| FDA / EMA / NMPA 指南正文 | CGT 技术指南 | 公开文件 | 见下 |

### 关于监管指南正文

FDA、EMA、NMPA 三家官网**均拦截自动化采集**（FDA 返回 404；EMA 部署 antibot 模块；NMPA 返回 412 WAF），联邦公报的全文下载亦重定向至其反爬页。这些文件本身公开且无版权障碍，受限的是自动化检索方式。本项目**不绕过此类反爬措施**，指南正文采用人工下载后解析入库的方式获取。

### 明确不可用的来源

- **ASGCT / AACR 会议摘要** — 有版权且会员墙，不入训练，仅在检索层按合理使用引用
- **非开放获取期刊综述** — CGT 高价值综述多在非 OA 刊
- **企业 IND / preIND 内部资料** — 商业秘密与合同风险
- **CC-BY-NC / ND 系列文献** — 本项目为商业用途，已在许可筛选阶段剔除（实测占开放获取文献的 33.4%）

## 评测方法

不采用主观打分。留出真实试验记录作测试集，**考模型能否复现其入排标准与终点设计**，按条目层面计算召回与精确率；同时在通科医学基准上检查持续预训练导致的能力退化。

## 已知局限

- **环肽模态语料近乎空白** — ClinicalTrials.gov 全库仅 9 项环肽试验，该方向的管线梳理只能依赖专利与文献
- **统计设计语料稀缺** — 仅 8.3% 的试验在公开记录中披露统计方案
- **高价值综述无法入训** — 见上
- 模型训练是否构成 CC 协议下的"演绎作品"在法律上尚无定论；本项目按最保守口径仅取 CC-BY 与 CC0

## 免责声明

本项目产出为研究与信息参考，**不构成医疗建议、诊疗决策或监管申报结论**。任何临床与申报决策须由具备资质的专业人员结合完整资料作出。

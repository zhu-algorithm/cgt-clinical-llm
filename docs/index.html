CGT Clinical LLM

细胞与基因治疗转化医学垂直语言模型 — 面向 IIT、preIND/IND 申报与临床方案设计

正式名称待定。候选名涉及在世医学家姓名，须取得本人或所属机构书面授权后方可对外使用。授权落定前，本项目对外一律使用中性代号。

定位

通用医疗大模型在细胞与基因治疗、孤儿药认定、早期临床设计这些细分语域上知识稀薄且易产生幻觉。根因不在对齐不足，而在基座语言模型没有这套语域的 token 分布——监管话术、终点设计、CMC 工艺描述是一套独立语域，几千条指令样本改不动模型对它的先验。

本项目因此采用先领域持续预训练、后指令对齐的顺序，服务对象为 PI、临床研究者、CRO、转化医学团队与药监申报人员。

架构：三层分离

能力进权重，事实进检索，数据库进工具。

层内容为什么在这一层

数据来源与许可

全部训练语料均为公有领域或允许商业再利用的许可。本项目不使用、也不接受从 Claude、ChatGPT/Codex 等商业模型蒸馏产生的数据——相关服务条款禁止用其输出训练竞争性模型，而一个对外收费的医疗申报产品不应把这类数据放进来源链条。

明确不可用的来源

  • ASGCT / AACR 会议摘要 — 有版权且会员墙，不入训练，仅在检索层按合理使用引用
  • 非开放获取期刊综述 — CGT 高价值综述多在非 OA 刊
  • 企业 IND / preIND 内部资料 — 商业秘密与合同风险
  • CC-BY-NC / ND 系列文献 — 本项目为商业用途，已在许可筛选阶段剔除（实测占开放获取文献的 33.4%）

关于监管指南正文

FDA、EMA、NMPA 三家官网均拦截自动化采集（FDA 返回 404；EMA 部署 antibot 模块；NMPA 返回 412 WAF），联邦公报的全文下载亦重定向至其反爬页。这些文件本身公开且无版权障碍，受限的是自动化检索方式。本项目不绕过此类反爬措施，指南正文采用人工下载后解析入库的方式获取。

评测方法

不采用主观打分。留出真实试验记录作测试集，考模型能否复现其入排标准与终点设计，按条目层面计算召回与精确率；同时在通科医学基准上检查持续预训练导致的能力退化。

已知局限

  • 环肽模态语料近乎空白 — ClinicalTrials.gov 全库仅 9 项环肽试验，该方向只能依赖专利与文献
  • 统计设计语料稀缺 — 仅 8.3% 的试验在公开记录中披露统计方案
  • 模型训练是否构成 CC 协议下的「演绎作品」在法律上尚无定论；本项目按最保守口径仅取 CC-BY 与 CC0

访问

推理端点处于口令内测阶段，不公开开放。医疗与申报场景下，一个未完成训练、未配置安全层与引用溯源的模型若被公开试用，损伤的是产品信誉，且可能被误当作诊疗或申报建议使用。

免责声明：本项目产出为研究与信息参考，不构成医疗建议、诊疗决策或监管申报结论。任何临床与申报决策须由具备资质的专业人员结合完整资料作出。

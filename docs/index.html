CGT Clinical LLM

细胞与基因治疗转化医学垂直语言模型 — 面向 IIT、preIND/IND 申报与临床方案设计

正式名称待定。候选名涉及在世医学家姓名，须取得本人或所属机构书面授权后方可对外使用。授权落定前，本项目对外一律使用中性代号。

定位

通用医疗大模型在细胞与基因治疗、孤儿药认定、早期临床设计这些细分语域上知识稀薄且易产生幻觉。根因不在对齐不足，而在基座语言模型没有这套语域的 token 分布——监管话术、终点设计、CMC 工艺描述是一套独立语域，几千条指令样本改不动模型对它的先验。

本项目因此采用先领域持续预训练、后指令对齐的顺序，服务对象为 PI、临床研究者、CRO、转化医学团队与药监申报人员。

关于监管指南正文

FDA、EMA、NMPA 三家官网均拦截自动化采集（FDA 返回 404；EMA 部署 antibot 模块；NMPA 返回 412 WAF），联邦公报的全文下载亦重定向至其反爬页。这些文件本身公开且无版权障碍，受限的是自动化检索方式。本项目不绕过此类反爬措施，指南正文采用人工下载后解析入库的方式获取。

评测方法

不采用主观打分。留出真实试验记录作测试集，考模型能否复现其入排标准与终点设计，按条目层面计算召回与精确率；同时在通科医学基准上检查持续预训练导致的能力退化。

已知局限

  • 环肽模态语料近乎空白 — ClinicalTrials.gov 全库仅 9 项环肽试验，该方向只能依赖专利与文献
  • 统计设计语料稀缺 — 仅 8.3% 的试验在公开记录中披露统计方案
  • 模型训练是否构成 CC 协议下的「演绎作品」在法律上尚无定论。本项目按最保守口径，仅接受 CC0、CC-BY 与公有领域标记三类；CC-BY-SA 一并排除——其 copyleft 条款有可能被解读为延及在该文本上训练出的权重，这个问题同样无定论，不应出现在商业产品的来源链条里

医保精算与控费板块

目标函数红线。本板块的优化目标是不当支付（improper payment）的减少，不是支付的减少。 一个被训练去最小化支出的模型，学到的会是拒付——因为拒付欺诈与拒付正当治疗，在「减少支出」这个指标上等价。 因此奖励函数中误拒的代价被显式设为高于误批：误批损失的是钱，可追回；误拒损失的是治疗，不可逆。

定位区分

政府基本医保是全民覆盖、不可风险筛选的，不存在核保环节——政府侧是「基金精算 + 支付审核 + 反欺诈」， 核保与风险定价属于商业健康险与惠民保。两者合并为一个板块会导致产品定位错误。

现状实证：同一病组的支付离散度

在覆盖 ≥50 家医院的 201 个 DRG 上：

1.86×同一 DRG 内 P90/P10 实付倍率（中位数）
3.15×该倍率的最大值
5.03×收费 / 实付 比（中位数）
这个离散度不等于浪费。它包含组内病情严重度差异、地区工资指数调整、教学医院与 DSH 附加、异常值支付。 它界定的是控费的搜索空间，不是可节约金额。任何把该差额直接折算为「潜在节约」的说法都没有依据。

控费策略分层：哪些该用经典方法，哪些才轮到大模型

环节应使用的方法大模型是否适用
基金收支预测、精算平衡信度理论、GLM/GAM、链梯法与 Bornhuetter-Ferguson 准备金、随机模拟不适用——经典精算模型在此严格优于大模型
账单异常识别分组内离群检测、医院—患者二部图分析、升级编码（upcoding）模式检验仅用于非结构化侧（病历与账单一致性）
支付范围与适应症限定判定——核心适用：规则是自然语言、病历也是自然语言，规则引擎在此失效
DRG/DIP 分组校验分组器规则适用于病案首页与病历叙述不一致的发现
欺诈调查取证人工审核辅助：生成可复核的证据链，而非给出分数

结论：医保控费的主体仍是精算与统计方法；大模型真正不可替代的位置，是把written rules 适用到 clinical narrative 上 ——医保目录的支付范围限定（限二线用药、限晚期、限特定检验值）正是这一类，也正是规则引擎做不了、而通用大模型会幻觉的地方。

已知局限

  • LEIE 与 CMS 账单数据不构成现成的监督式反欺诈数据集。实测：LEIE 中仅 10.6%（8,924 条）带有效 NPI， 可归为欺诈类定罪且带 NPI 的仅 4,335 条；对其中 25 个欺诈类定罪 NPI 抽查，在 2024 年度 Part D 处方文件中命中 0 个； 另按排除年份分层抽查 50 个已排除 NPI（未限定欺诈类）亦命中 0 个。过滤语法已用真/假 NPI 对照验证有效。构造训练集须按各机构排除日期对齐历史年度文件，且正类上限约 4,335。
  • 中国个人级医保结算数据不公开。公开的只有国家医保局汇总统计与规则文本（CHS-DRG 分组方案、DIP 病种库、医保药品目录及支付范围限定）。 现实路径是用美国公开理赔数据训练模型能力、用中国规则文本训练规则适用能力，个人级数据须由需方在机构协议下提供。
  • 欺诈标记必须是可复核的证据，不是分数。受基础发生率影响，任何单一分数都会产生大量假阳性；本板块的输出形态绑定引用溯源头。

访问

推理端点处于口令内测阶段，不公开开放。医疗与申报场景下，一个未完成训练、未配置安全层与引用溯源的模型若被公开试用，损伤的是产品信誉，且可能被误当作诊疗或申报建议使用。
